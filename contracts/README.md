# Ortak sözleşmeler

Tek asıl kaynak source/python/packages/contracts içindeki Python modelleridir. generated/ altındaki JSON Schema ve OpenAPI mevcut dışa aktarımlardır; TypeScript üretimi henüz uygulanmadı. Paralel elle düzenlenen model kopyası oluşturma. Sözleşme değişikliğinde üretim ve geriye uyumluluk ayrıca kontrol edilir.
