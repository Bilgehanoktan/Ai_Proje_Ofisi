# Altyapı

Yerel Windows/Linux, servis, izolasyon, ağ, gözlemleme, yedek/kurtarma ve paketleme tanımları bu alanın sorumluluğudur. Mevcut PostgreSQL yönetim aracı scripts/database içindedir. DB data, özel anahtar ve gerçek profil burada tutulmaz. Kubernetes/Terraform zorunlu değildir; geçişte servis kurulmadı.
